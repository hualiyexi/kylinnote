KylinList (麒麟清单) for Windows x64

KylinList is a local task and checklist manager with schedules, reminders
and optional desktop notes. Extract the complete directory before running
kylinlist.exe. Qt libraries, platform plugins, SVG plugins, SQLite driver,
and MinGW runtime are included. You do not need to install Qt or change the
system PATH.

Windows 10 / 11 x64 are the tested targets. Unicode and space-containing
installation paths are supported. The Setup executable installs only for the
current user and does not need administrator privileges.

Tasks and settings are saved in the current user's local application data
folder, outside this program directory. New backups use the .klb extension.
Legacy data, settings and backups are not migrated; an existing notes.db is
neither read nor deleted. Uninstalling the application preserves these user
files. Back up the data folder before deleting it manually.

Start-at-login is controlled by the application setting and is disabled unless
the user enables it. Setup does not force it on.
