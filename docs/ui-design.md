# 麒麟清单界面设计

服务对象是在离线办公机上使用中文软件的人。任务与清单是核心，便签是任务在单台设备桌面上的投影，关闭便签不删除任务，也不改变其他设备状态。

当前规格核对：2026-11-18。以下为本轮现行 UI 契约；历史依据与取代关系见 [UI 对齐契约](ui-alignment-contract.md)。构建、自动化结果与未覆盖边界见[更新说明当前条目](updates.md#当前实现与验证状态)；原生视觉与实际手势由用户亲自验收，不新增人工验收截图。数据准入为 schema10 新库／当前库、备份仅当前 v6；开发期旧预览库直接换新数据目录重建，不做迁移，详见[数据模型](data-model.md)。

本机名称与 logo 定制仅通过外部 `Branding` 配置；私有显示名、配置路径和 logo 不写入源码、文档、测试、资产或其他受跟踪文件。第一列首行是同一品牌的透明 Logo，不再使用样式头像；保留34×34按钮和本机工作区菜单，不给第一列入口加固定白底。应用窗口、任务栏与托盘使用共享 `BrandingIcons` 的等比白底版本，白底取独立的 `AppIconBg` 语义令牌、深浅主题均为白色；原图不改写，提供多尺寸／DPR，无配置则统一默认品牌回退。不改变产品标识、安装身份或安装菜单资源。

## 2026-11-17 当前调度与四列细节

- 四列首行共用 **48px 中线**，窗口按钮仍为28px；Logo 34×34，智能清单／收集箱行高35px，普通清单与文件夹保持原导航行高。亮色第一列 `#F9F9F9`，第二至第四列全部 `#FFFFFF`。
- 第三列前置任务／笔记图标仅绘制下移1px，命中区不动。选中与悬浮都保留下分隔线，右端与选中背景对齐；状态顺序为**清单 → 闹钟 → 附件 → 笔记**，存在性来自快照索引，窄行按预算省略，不在 paint 中查 SQL 或文件系统。笔记即使保存日期也不显示第三列日期文字／提示。
- 第二列数量使用至少24px独立栏，8px色点与数量栏间距4px、右侧内边距12px，数量位数不挤动色点。已归档清单按普通文件夹绘制左箭头、正常字体和颜色，不伪造真实文件夹ID。
- 第四列笔记保留信息按钮；任务同位置显示当前优先级旗子，打开164px可见卡片、34px行、18px旗子的四档竖向菜单，当前值右侧勾选。任务／笔记互转不再二次确认，成功后才在所属窗口底部显示“已转换”。
- 日期按钮左右各4px，图标和文字按实际字体的墨迹中线对齐；有计划未过期用稳定 `Info=#4772FA`，已过期用 `Overdue=#E13E39`。普通与覆盖详情头栏均左右对称留白。头栏放不下完整日期与时刻时，日期按钮移到头栏下一行，必要时换行，不用省略号截断时间段。
- 详情日期按本年「M月d日」、其他年份「yyyy/MM/dd」显示。带时刻的时间段将时刻紧跟对应端点；同日时间段仅写一次日期。说明以应用时区的今天为基准、时间段取结束日：昨天／今天／明天／后天优先，至下周末使用「周X」／「下周X」（沿用月历的周起始日），更远或早于昨天的进行中任务显示「剩余N天」／「延期N天」。日期跨天后刷新文案，完整日期与时刻不受说明影响。
- 第四列底部清单选择器与右键“移动到”共用 `ListDestinationMenu`：透明无边框搜索框、前置18px search-thin、独立分隔线；根层为文件夹和平铺清单，文件夹使用原生悬浮／键盘子菜单。搜索时展示扁平结果及文件夹路径，按UUID移动，不归档目标混入可选列表。
- 设置弹窗为约212px左栏＋右侧正文：左栏 `#F8F8F8`、选中 `rgba(25,25,25,.04)`／8px圆角，正文分组 `rgba(25,25,25,.02)`／10px圆角，卡片20px圆角。全局、自绘、局部QSS和原生Fusion统一清理蓝色焦点框，保留Tab／方向键／回车／Esc。
- 日期弹窗以 `ScheduleValue` 管理单日、完整时间段、多提醒和完整重复规则。快捷按钮一次提交关闭；完整规则与范围字段保存到schema10，子弹层取消不写库。正常提醒不含持续提醒开关、状态或重复投递；法定节假日与艾宾浩斯记忆法不实现。
- 任务和笔记均可设置日期与正常提醒并实际通知；笔记提醒弹窗无“完成”。时间段按范围相交参与“今天／明天／最近7天”，按结束日判断逾期，按开始日排序，不再共用一个模糊的 `effectiveDate`。

## 设计系统架构

颜色、字号、字体、间距通过**语义令牌**统一管理，不在业务代码中硬编码。架构借鉴 CaseLawLibrary / public-interest-litigation-fund 的三层设计令牌：

```
design/DesignTokens.h   原料层（ds::raw）：裸色值 QRgb，唯一合法来源
       ↓
design/DesignTokens.h   语义层（ds::semantic）：ColorToken 枚举 + 每主题值表
       ↓
design/QssBuilder.cpp   元素层：QSS 由生成器产出（Qt 无 CSS 变量）
       ↓
业务代码                 只引用 AppStyle::color() / ThemeManager::instance().color()
```

### 主题切换

支持 **浅色 / 深色 / 跟随系统** 三态，运行时切换、QSettings 持久化、无白闪。入口：第一列“设置” → “外观” → “主题”。

第一列 Logo 的“本机工作区”菜单保留使用统计、检查更新、更新服务器和退出，不再包含自启；底部“同步与数据”统一承接导出备份、覆盖导入与打开数据位置，后续云同步复用同一入口。设置对话框新增「通用／开机自启动」开关，正式安装版默认开启并可在同一处关闭；外观、智能清单沿用现有页面。左侧212px栏与右侧内容不变，标题栏横跨整张卡片，关闭按钮位于右上角。

- 浅色值来源：考据静态资源与 Web 现场（考据资料只在本机，未入库）。
- 深色值为 KylinList 自定（考据无深色色值证据）。
- 所有 SVG 图标随主题着色（`AppIcons::icon()` / `AppIcons::paint()`）。

### 阴影与浮层外观

所有窗口阴影由应用自绘，不接受系统补画：

- 自有浮层（信息、清单选择、日期选择器、格式岛、选中文字气泡）在窗口标志中声明 `Qt::NoDropShadowWindowHint`，圆角与投影都由 Qt 绘制。
- Windows 仍可能给无边框窗口的窗口类加上 `CS_DROPSHADOW`。`kl::disableNativeWindowShadows()` 在创建原生句柄时统一清除该样式，覆盖菜单、下拉列表、提示框等 Qt 内部弹出窗口；应用启动时安装一次。
- 这样圆角卡片外不会再出现系统画的直角阴影；新增浮层不需要各自重复处理。
- `PopupMenu`、`AnchoredListPopup`、关联独立窗口与格式岛复用 `PopupShadow`：24px 透明外边距，整张圆角 alpha 图做 sigma6／核半径18／峰值0.20 的可分离高斯模糊，返回预乘图像并按几何与主题缓存。菜单和日期子层保留12px圆角，关联窗口普通状态16px，格式岛使用10px；不用 `QGraphicsDropShadowEffect`、多层描边或 `setMask`，内容边界与阴影范围分开。

### 清单按钮与文字中线

第四列底栏仍为48px高，右侧A与更多入口不变。左侧`GroupChip`使用局部复合绘制：18px图标盒、正文级10.5pt字体、4px图文间隔；图标与文字按实际解析字体的稳定参考墨迹中线共同定位，不借用导航图标下沉偏移，不缩小字号。保留长名称省略、最大180px宽度、可访问名称、原清单选择弹层与真实点击命中；同一`TextGeometry`中线定义也用于正文空行加号。

### 关联详情与共享编辑

正文的任务／笔记关联打开无QWidget父对象的独立`Qt::Window`，窗口内复用一个完整`TaskDetailWidget`，常规内容610×500px、16px圆角与24px阴影边距，阴影复用`PopupShadow`、下偏移5px，边框由鼠标透明overlay最后绘制。28px标题条提供最小化／最大化／关闭，顶部拖动、双击最大化，四边和四角均可调整；最大化取消圆角、阴影边距与缩放手柄。内容角与阴影分别处理，不用`setMask`或另一套graphics effect。原第四列不搬走、不因关联导航更改筛选、搜索、选中、正文滚动或撤销栈；主窗口不重置关联窗口几何，也不因自身Escape、快速添加或普通导航误关。重复／自引用不重置当前窗口，循环关联继续复用它。便签正文同路由；主任务链接、创建结果和便签更多菜单“打开主窗口”仍为原导航意图。

点击窗口外不自动关闭；Esc先由IME与日期／格式／补全／选区／链接工具等子交互处理，随后才关闭窗口。标题栏关闭、换目标和退出都检查`finishEditing()`；文字或会话日志失败保留草稿与窗口。详情和便签共享`EntityTextSession`即时草稿，持久化仍共用`TextDraft`字段基线校验：不同字段可合并，外部同字段真冲突整份拒绝，不恢复已删除实体；错误区提供复制草稿、经确认丢弃并重新载入，以及Ctrl+S重试。恢复失败解冻并保持上下文，成功则先清除旧窗口／便签上下文，不能让旧编辑器写回新库。

### 字体系统与内置字体

字体族通过 `design/TypeSystem.cpp` 与 `FontManager` 统一解析。默认选项保留平台可缩放中文无衬线回退链；用户还可在“设置 → 外观 → 字体”选择随包内置的 **Noto Sans CJK SC** 或 **霞鹜文楷**。业务代码只走 `ds::qfont(FontScene)`，统一使用 `QFont::PreferAntialias | QFont::PreferOutline`，不裸构造业务字体。

- 随包文件为官方静态 `NotoSansCJKsc-Regular.otf`／`NotoSansCJKsc-Bold.otf` 与 `LXGWWenKai-Regular.ttf`／`LXGWWenKai-Medium.ttf`，均为OFL；来源、版本与SHA-256见`THIRD_PARTY.md`，许可证全文随资源和安装包提供。
- 字体偏好保存稳定ID，族名只取 `QFontDatabase::addApplicationFont()` 的实际注册结果；选项仅在常规／粗体都成功加载时出现。Windows使用程序旁`fonts/`，随包Qt使用`lib/kylinlist/fonts`，系统Qt使用`share/kylinlist/fonts`；构建同时复制到开发预览程序旁。无需联网、安装系统字体或目标机预装。
- 切换字体通过统一通知刷新现有窗口、菜单、列表和详情。正文只调整现有字符格式，不重建文档，保留正文、选区与撤销记录；等宽代码和内置Emoji字体独立，不随界面字体覆盖。Qt 5.12注册和麒麟ARM64真机字形分别记录，不混为已验收。

**内置 Emoji 字体**：`src/resources/fonts/NotoEmoji-Regular.ttf` 是 OFL 许可的 Noto Emoji 静态 Regular 400 子集，随应用安装到可执行文件旁的 `fonts/`（普通 Linux 安装使用字体搜索路径）。`TypeSystem` 注册实际字体族后优先使用单色字形，避免老旧系统没有 Emoji 字体时显示空白或方框。现有 Emoji 字符串与自定义选择器不变；超出内置字符表的序列不保证支持，麒麟真机表现仍需用户验收。字体许可证随包提供。

**offscreen 测试的环境问题**：Windows 的 Qt offscreen 平台插件不读系统字体目录，会报 `Cannot find font directory ...` 并退化成无字形截图。`CMakeLists.txt` 已为 Windows 测试自动设置 `QT_QPA_FONTDIR=$WINDIR/Fonts`，CTest 与 `visualPreview()` 截图不再缺字。真实 Windows 桌面与麒麟目标机不走 offscreen，不受影响。

### 分组与显示偏好

- 五种模式为 List／Time／Created／Priority／None，与范围、搜索和计数正交。文件夹默认 List，其他范围默认 Time；单清单／收集箱不提供 List。按 scope／清单或文件夹 ID 在本机 `QSettings` 保存 `grouping` 字符串，不写业务实体或活动日志。
- 活动列表共享 **pinned → 普通模式组 → notes → completed → abandoned** 顺序；None 只取消普通任务的组标题，不取消特殊区。`showCompleted` 同时显示已完成和已放弃；显示设置新增对应复选框，原菜单 quick toggle 与它共用同一状态，不做第二套偏好。
- Time 六桶为 expired／today／tomorrow／next7days（今天+2..+6）／later（+7 起）／undated；expired 的实现稳定键为 `time:overdue`。Created 四桶为过去7天（0..6）／过去30天（7..29）／更早／未知（含未来兜底）。组内 `sortOrder ASC → 自然字段 → id`，终态默认对应时间倒序。
- Completed／Abandoned／Trash 历史视角也提供全部五模式，并真正重分组；筛选集合保持不变、所有模式只读禁拖，不保留活动视角的 pin／notes／终态页脚。选择 Time 不是把普通范围变成日期筛选。
- Created 模式实际起拖时在第三列底部 `WorkspaceToast` 提示“创建时间分组不允许拖放”，不只是静态 tooltip；Store 同样拒绝，零写入。终态目标拒绝，Notes 不触发 Task／Note 隐式转换。

### 任务动态

- `ActivityTimelineWidget` 在第四列正文滚动流下部，与标题、正文共用 `DetailScroll`，可关闭；附件在该滚动区之外的底部独立面板，不另开日志对话框。通过 `eventsChanged(entityId)` 刷新，隐藏期间标记 dirty，重新显示补刷；仅事件提交也要刷新。
- 标记 20px、摘要 14px、时间 12px／20px 行高、文字左缩 32px、条目间距 20px、连接线 1px；标题上／下留白 18px／8px，关闭图标 18px，最新事件在前。
- 只显示 `ActivityPolicy` 的实质字段与生命周期白名单，不记录排序、pin 或外观。创建摘要有标题；主任务标题、清单名和附件名从 `EntityEvent.context` 的当时快照读取，旧空上下文用通用文案，不泄露 UUID／批次号，不展示全文。
- 没有账号就不伪造 Actor、昵称或头像；面向用户的父级称“主任务”。标题／正文仍按独立编辑会话记录，结束会话失败保留编辑内容，不假装保存成功。

### 已有正文的排版可见性

加载已有正文时，不能仅以`content()`或数据库字段非空作为显示成功：真实可见的QTextEdit必须有有效文字行，文字墨迹存在，完整插入符矩形落在viewport内，并可从实际命中区点击编辑。

Qt5.12中，仅通过`setBlockCharFormat()`修改段落字符格式可能清空该段的QTextLayout；如果未继续写字符格式，布局便可能缺少重新排版通知。当前统一由`MarkdownDocument::renderBlock()`在实际块转换后标记当前block为dirty；已有源码、可见文本与语义快照一致的块直接保留，不在getter／paint里全量重排，也不以延时或加高度掩盖。回归从真实TaskPanel列表选择含正文和附件的实体，检查首行布局／实际墨迹／光标／输入保存，另覆盖单行、多行、格式化、空与非空切换及宽窄重挂。

### 空正文与短正文的可编辑区域

第四列的真实 `QTextEdit` 是正文区唯一伸展项：**空正文与短正文都填满可用留白**，不能出现“有一行文字之后其余背景不可点击”的尾部弹簧，也不能只在没有附件／动态时才启用。附件已移到独立底部面板，不再迫使短正文恢复成一行自然高度；布局为正文优先保留至少120px预算。长文继续通过外层 `DetailScroll` 滚动，不在正文内部再嵌套滚动条；桌面便签的普通滚动编辑不受影响。

悬浮仅显示 IBeam 文字指针，不抢标题或其他控件焦点；点击实际 viewport 后由 QTextEdit 原生聚焦、放置插入符并接收输入，沿用编辑会话／自动保存。空／非空切换、附件增删、动态显隐、窗口缩放与只读状态变化均重算布局；不加透明点击层、不全局转发背景点击，不伪造不可编辑的正文留白。

### 正文即时格式与编辑文档

正文使用持续存在的`QTextDocument`富文本模型。`MarkdownDocument`负责块类型、行内格式、Markdown读写和UTF-16源映射，`MarkdownEditor`负责宿主、格式命令与链接／补全，`EditorTextEdit`继续交由Qt处理键盘、输入法、选区和撤销事务。Qt5.12.8没有`setMarkdown()/toMarkdown()`；保留内置MIT MD4C的安全HTML预览，不增加浏览器运行时或新依赖。

行首`# `至`###### `立即转换标题，包括空标题的插入符和默认输入格式；成对行内标记和格式菜单操作当行呈现。当前行不再整体展开为源码，光标移动、选区与失焦／聚焦只处理交互状态，不改变字号、块边距、换行宽度或撤销历史。闭合行内标记后在外侧继续输入为普通文字，回到已有样式内编辑则继承该样式。标题回车后落正文，列表续项、有序编号递增、检查项续出未完成状态，空项回车退出；块起始退格还原正文。

Markdown仍是`Entity::body`的持久化格式。块／字符语义和源映射存入可撤销的Qt格式属性，未修改块保留原文，修改块按实际字符格式写回，跨样式替换和跨段合并保留有效格式。精确源范围的命令直接操作源文本，不经压缩后的可见选区往返；独立编辑器的单次格式、检查项切换、引用确认和粘贴沿用Qt撤销历史，绑定实体的视图则由下述共享源历史统一负责。IME preedit不进入正文、不重写组合所在块，提交后再转换；不在每次输入时调用`setContent()`重建全文或清空撤销。

### 桌面便签与实时联动

桌面便签复用`TaskDetailWidget`的紧凑布局与`MarkdownEditor`，不再另维护预览／编辑栈、完成框和编辑按钮。纸面为7px抗锯齿圆角，内容左右14px留白，标题前保留20px可拖动区，底栏高26px；左下日期始终显示并打开完整共享日期选择器，右下20px更多仅悬浮可见。顶部外观、置顶、关闭各18px命中／12px图标，只随悬浮显现并保留布局占位。更多提供当前已实现的新建、完成、排列、打开主窗口、窗口层级／应用设置和删除；完成只在菜单／Ctrl+M，关闭保留任务，删除进入回收站。六种纸色及便签内文字、边框和控件配色集中在 `ds::`，独立于应用深浅主题。附件沿用同一56px卡片，省略标题行，左右14px，采用独立有界滚动并给正文保留48px预算。

便签的24px透明边距由共享`PopupShadow`绘制；对128px小模板生成整场高斯阴影，连续缩放时九宫格伸缩，不重新卷积整窗。纸面边框用鼠标透明overlay最后绘制，不遮内容或拦截操作。四边／四角透明缩放热区位于可见纸面边缘，不能吞掉底栏更多按钮；最小纸面220×180px。`NoteSnap`只对可见纸面计算工作区边缘、同边对齐及0／8px邻接间距，捕获阈值10px；拖动保留原始指针位移，便于拖出吸附区。横／纵排列按屏幕可用区换行，恢复几何也只约束纸面，阴影不增加实际间隔。

同一实体的主详情、关联详情和便签共享`EntityTextSession`。原始标题和Markdown正文在真实输入事务结束后立即广播，450ms合并持久化只影响磁盘写入；观察视图不再次保存、不新建会话。每个视图仍有独立的富文本投影、换行宽度、光标和滚动，远端更新按可见文本差分恢复局部选区，尤其不能把链接标题内的部分选择扩大成整链。标题与正文各自持有一份共享源撤销／重做；键盘和右键菜单路由到共享历史，Qt投影变化不计入撤销。IME预输入只留在本地；已提交字与下一段预输入并存时仍即时同步，远端更新不重写正在组合的文档，组合结束后再安全重定位。持久化仍走`TextDraft`三方校验，只回写实际改变的字段；空白标题保留草稿并阻止关闭，但有效正文照常保存。SQL、日志和重入更新失败均保留窗口与草稿；明确重载可在目标删除后丢弃草稿，不复活实体。日志只归因真实写入的字段。恢复成功使旧会话和撤销上下文失效，失败保持原稿。

### 托盘与任务小部件

托盘右键使用麒麟清单的圆角浮层，提供「添加桌面小部件 → 任务」「主窗口置顶」和「退出」。任务小部件也可通过「设置 → 桌面小部件」打开。两处入口操作同一个窗口。

小部件默认显示收集箱，标题可切换到今天、明天、最近7天、所有或普通清单。窗口复用第三列的任务行、完成框、日期和上下文菜单。右上角选项用于独立设置分组、终态可见性、正文摘要、日期倒计时与主题。拖动顶栏或缩放边缘可调整位置与尺寸。应用退出时保存小部件的打开状态和设置，下次启动恢复仍打开的窗口。

### 正文 gutter、块菜单与格式岛

- `EditorTextEdit` 的 gutter 是正文之外的真实保留区域，不覆盖文字、不向背景转发点击。加号只属于当前聚焦且可编辑的真正空源码普通段落：选区、IME预编辑、失焦、空白字符行、代码围栏与分隔线都不显示，不再随鼠标悬浮换行。22px命中区／14px字形按QTextLayout基线与字体参考墨迹中线定位，NoFocus且普通／hover／pressed／focus均无背景；菜单打开导致失焦后，已保存的源码锚点仍有效。段落、三级标题、无序／有序列表、Markdown任务列表、引用与分割线共用块样式API，非空段落转换走格式入口。
- Markdown任务列表`- [ ]`／`- [x]`的14px检查框按块语义独立绘制，不使用混入文字的☐／☑占位。检查框、列表圆点／序号和引用条以段落首行的布局原点定位，结合文档到viewport的实际滚动偏移换算；不得用`cursorRect(QTextCursor(block))`作为装饰锚点，因为空段落的该矩形会随IME预编辑光标移动。空项预输入、候选光标移动、取消和首字提交时标记保持在行首，预编辑文字与光标仍由Qt正常处理。按下与释放均命中检查框才切换完整状态，保留原光标、选区和滚动位置，文本区继续原生编辑，只读不切换；状态参加正文撤销／会话，不创建独立检查项实体、UUID、完成业务或进度模型。
- 选区 `SelectionBubble` 可见卡片高 **32px**，按钮实际高 **24px**，布局上下各 **4px**；**18px glyph box** 因而上下各约 **7px** 留白。底栏 `FormatPanel` 保持 **36px** 紧凑单排、常规卡片宽 **304px**。两者均为 **10px** 抗锯齿圆角、自绘主题底色与共享阴影，尺寸不含20px透明阴影边距。
- 选区直接提供文本类型下拉、加粗、斜体、删除线、下划线、高亮、代码、链接和更多；文本类型列出上述块样式。窄边界把低优先级动作折叠到**同一个纵向菜单**，保留更多入口，不能整条消失。选区更多不再生成第二条横向 FormatPanel。
- 格式更多、色板和文本类型使用共享 `PopupMenu` 的 `entityMenu` 样式，不新建普通 QMenu：**34px 行高、4px 行外缩进、12px 卡片圆角、18px 图标**，并沿用标准分隔线。常规更多顺序为附件、链接、关联任务/笔记、引用、代码、分隔线、清除格式；响应式折叠动作在同一菜单分组，不能丢掉原有功能。
- 不创建或保留隐藏／屏幕外 `EditorToolbar`、`format0..` 等假格式控件；鼠标入口、快捷键与测试共用真实动作 API，不用不可见替身按钮证明功能存在。
- 保存选区时使用绝对UTF-16**源码偏移**及`contextGeneration`，以sourceSelection／selectSource跨弹层失焦和文档局部转换恢复；不再靠FocusOut切换源码／呈现，也不能跨弹层持有原始QTextCursor。自有菜单通过 `markdownEditor` 属性／ownsPopup 判断焦点归属，活动期间不丢选区或误关闭。setContent／setStore／setEntityId 改变上下文后，旧弹层和迟到回调不许写入新实体／新正文；祖先裁剪、滚动、窗口隐藏与边界变化仍须正确收起或重定位。

### 正文引用、补全与链接编辑

内部引用只保存为 **`[[UUID|literalalias]]`／`[[UUID]]`**。有别名就按字面显示、不执行 Markdown／HTML，也不因目标改名而改写；无别名才读取目标当前标题。渲染的内部导航 href 为**裸 UUID**，编辑区与预览区共用处理；不读旧 scheme，不双读、不做迁移回退。完整语义见[数据模型](data-model.md#引用正文内链)。

输入 `[[` 或使用“关联任务/笔记”后，通过非模态候选按标题**包含**匹配任务／笔记；IME preedit 不被当成最终查询或确认，Escape 只取消候选，不误插入、不删除原输入。链接悬浮工具提供复制／编辑；编辑弹层仅有“文本”和“链接”两字段，分别编辑显示文字与外部地址／内部实体标识，确认才写入、取消不改。格式、补全与链接弹层都遵守同一源码偏移和上下文代际安全边界。

### 附件卡片与文件操作

第四列附件位于**底栏上方的独立底部面板**，不随标题／正文的 `DetailScroll` 流动；有附件时显示标题、数量与添加入口，空时整区隐藏。左右各 **24px**，有自己的有界滚动区；面板高度同时受**最多三张卡片**、宿主可用高度 **1/3** 以及为正文保留至少 **120px** 的预算约束，标题／分隔／内边距也计入预算。超过可见预算只滚附件，不拉长正文区，不挤掉正文、底栏或外侧宽度；缩放、覆盖／停靠重挂和增删附件时重算。

底部附件使用 **56px高／14px圆角／6px间距** 的文件卡片，左侧 **26px** 类型图标，文件名 **14px等效（Body 10.5pt）** 与文件大小 **12px等效（Caption 9pt）** 两行排列；两行各取字体自然高度、1px行距，作为一个整体在卡片内垂直居中，不能把文件名行拉高、将大小贴到底边。右侧为18px `more-titlebar` 图标及30×30px命中区。布局与图标标识核查过参考网页DOM／计算样式；浅色类型底色结合用户提供的客户端图，深色为本项目配色，均集中于 `ds::` 令牌。复用已有 `doc/xls/ppt/pdf/text/zip/audio/video/photo/other` 资源，不加入品牌logo或新资产包。

`AttachmentAppearance` 只负责类型、图标、B／KB／MB文本，不进入数据库模型。类型规则为：图片优先使用图片类型，常见扩展名匹配文件种类，明确MIME作兜底；未知扩展名不因内容是纯文本就全部当txt。文件名保留完整tooltip／无障碍名称，显示时省略但保留扩展名，不撑宽卡片、不挤掉操作按钮。

点击整卡、Enter 或 Space 用系统默认程序打开附件。应用对附件做完整性校验后再交接带后缀的临时副本。省略号与右键共用 `PopupMenu`，图片还有「预览图片…」，所有附件均可另存，只读详情可打开、预览和另存。另存沿用 `copyAttachmentTo()` 的 SHA 校验和 QSaveFile 原子提交，确认后复核当前存储、实体与附件指纹。删除仅移除应用副本，沿用统一确认对话框。文件失效或操作失败通过 ModalDialog 反馈。

### 附件拖入

整个可写详情及其标题、正文和附件区都接收本地单／多文件。支持标准文件 URI 和 Peony 的编码 URI，并在有效拖入时显示“松开以添加附件”。导入复制文件，保留源文件和正文。应用先运行 `finishEditing()`，保存失败则零导入。拖入和选择器共用同一导入流程，单个文件上限 2 MiB。多文件逐个提交，遇错报告并停止，已成功的文件保留。

### 日期、时间、提醒与重复子层

日期入口仍共用 `TaskDateController`／`DatePickerPopup`。时间、提醒、重复使用独立 `AnchoredListPopup` 锚定子层，不再按固定 540px 高替换整个父页。

- 可见子卡片宽 **252px**、列表行高 **34px**、圆角 **12px**，宽高不含阴影。时间卡片总高 **≤280px**：自定义输入等固定区不压缩，列表只占剩余预算；提醒／重复按自然内容限高，不撑满同一个大页面。
- 可见卡片从入口下缘向下 **4px** 展开，下方不足先压缩列表，到最小可用高度仍不够才翻上；结合可用屏幕与父月历边界定位，不把整个月历盖掉。
- 日期／时间模式按钮无 focus 描边，仍为 `StrongFocus`、`autoDefault=false`，保留键盘可达及选中态，不能用 `NoFocus` 掩盖样式问题。
- 展示引擎实际支持的每天、每周、每月、每年、工作日与自定义重复；自定义提供公历／农历、按到期／完成日期、自选日期及结束条件，保留完整类型化规则。不展示原始RRULE编辑器、持续提醒、法定节假日／跳过节假日或艾宾浩斯记忆法。
- 子层确认只更新父层草稿；子层取消或 Escape 只关子层并把焦点还给入口，不关闭父层。父层取消 **0 写入**，只有父层确定才保存，取消子层不销毁父层其他日期／提醒／重复草稿。

**不设置常驻状态栏**。备份成功、本机数据说明、完成／放弃任务等反馈统一使用 `ToastIsland` 提示岛，位于第三列底部居中。组件封装文本、可选动作与生命周期：默认 3 秒消失，悬停暂停并在离开后按剩余时间继续；新提示替换旧提示，动作执行后立即关闭。完成／放弃提示提供撤销，恢复操作前任务状态。提示岛使用截图指定的固定深灰底、浅灰文字和金色撤销图标，**不随主题切换**；业务代码不拼接其颜色或定时器。保存或恢复失败仍显示就地错误，不静默丢弃编辑内容。

### 按钮收纳原则

- **直接可见**：日期／提醒、信息图标、文档标题和正文、底栏所属清单与格式入口。
- **正文与底部附件**：标题／正文／可关闭动态共用正文滚动流；附件独立有界滚动、空时无占位。没有独立检查项业务模型，复选框只作为可编辑 Markdown 标记；不提供旧内容转换入口。
- **格式操作**：底栏 A 展开36px单排格式岛，选区为32px气泡；文本类型、粗体、高亮、列表、斜体、下划线、删除线等共用真实动作 API，更多与色板使用共享列表 PopupMenu。块 gutter／加号也是真实入口，不能用隐藏／屏幕外格式控件替代。
- **实体操作**：完成状态、优先级、置顶、贴桌面、类型转换、任务动态、便签外观 → 详情更多菜单。
- **显示操作**：五模式分组、两种终态／详情显隐、日期显示方式与窄窗详情样式 → 列表头部 overflow 菜单；未实现的看板等呈现不展示入口，任务动态按第四列内嵌契约呈现。
- **应用级**：导出／导入备份、打开数据位置 → 第一列“同步与数据”；主题、智能清单与开机自启 → 第一列“设置”；使用统计、更新与退出 → 第一列 Logo 的“本机工作区”菜单。

## 交互约定

- 新建必须有标题；内容防抖自动保存，保存失败保留编辑内容、显示可操作错误，不悄悄覆盖。
- 所有格式按钮有 SVG 图标和工具提示；低频格式收进二级菜单。
- 时间没有勾选即无约束；默认时区为 `Asia/Shanghai`，带时刻的日期按任务时区显示、以 UTC 时刻保存。
- 删除任务进入回收站；永久删除二次确认；关闭便签只取消贴到桌面。
- 菜单/文本编辑不抢全局 Ctrl+N/Ctrl+D，快捷键只在应用内生效。
- 主题切换运行时生效，所有控件、图标、自绘 delegate 同步更新。
