# 待办界面设计

服务对象是在离线办公机上使用中文软件的人。任务是唯一业务对象，便签是任务在桌面的投影，关闭便签不删除任务。

## 视觉约定

- 工作区 `#F4F6FA`，编辑面 `#FFFFFF`，文字 `#23324B`，主操作 `#315BA6`，次级文字 `#64748B`，警示 `#AF3E38`。
- 使用 Windows 的微软雅黑 / Linux 可用的 Noto Sans CJK SC、文泉驿微米黑及系统无衬线字体；标题 16–20pt，正文 10–11pt，辅助 9pt。
- 内容左对齐。列表通过行分隔和选中底色建立层次，不把每个任务包进独立卡片。
- 便签用淡黄色、蓝、绿、粉、紫、白；保留边框和醒目的完成框，颜色辅助辨认、不承载唯一的状态信息。

## 布局

```text
┌──────────────────┬──────────────────────────────┬────────────────────────┐
│ KylinNote        │ 今天 / 全部任务   搜索        │ 完成状态 / 贴到桌面    │
│ 今天             │ 快速添加任务                  │ 标题、分组、优先级     │
│ 全部 / 即将到期  │ □ 任务标题      时间/优先级   │ 时间段、重复、提醒     │
│ 已完成 / 回收站  │ □ 任务标题      分组          │ 备注工具栏及预览       │
│ 我的分组         │                               │ 子任务清单、标签       │
│ 分组管理 / 备份  │ 显示数量及操作状态            │ 保存状态、回收站操作   │
└──────────────────┴──────────────────────────────┴────────────────────────┘
```

复核后取消了仪表盘统计卡和大色块标题，因为它们分散了“看到要做的事、立即记录”的注意力。面板使用原生窗口边框方便系统拖动与缩放；便签保留无边框拖动条。小窗口允许分栏拖动与详情区滚动。

## 交互约定

- 新建必须有标题；内容防抖自动保存，保存失败保留编辑内容、显示可操作错误，不悄悄覆盖。
- 所有常用格式有中文文字按钮和工具提示；Markdown 支持标准语法，统一用 Markdown 编辑；旧便签只迁移文字，不维护第二套富文本编辑模式。
- 时间没有勾选即无约束；日期统一按用户本地显示、UTC 保存。提醒需应用在运行，休眠恢复/重启后补发一次。
- 删除任务进入回收站；永久删除二次确认；关闭便签只取消贴到桌面。
- 菜单/文本编辑不抢全局 Ctrl+N/Ctrl+D，快捷键只在应用内生效。
