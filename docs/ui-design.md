# 麒麟清单界面设计

服务对象是在离线办公机上使用中文软件的人。任务与清单是核心，便签是任务在单台设备桌面上的投影，关闭便签不删除任务，也不改变其他设备状态。

## 设计系统架构

颜色、字号、字体、间距通过**语义令牌**统一管理，不在业务代码中硬编码。架构借鉴 CaseLawLibrary / public-interest-litigation-fund 的三层设计令牌：

```
design/DesignTokens.h   原料层（ds::raw）：裸色值 QRgb，唯一合法来源
       ↓
design/DesignTokens.h   语义层（ds::semantic）：ColorToken 枚举 + 每主题值表
       ↓
design/QssBuilder.cpp   元素层：QSS 由生成器产出（Qt 无 CSS 变量）
       ↓
业务代码                 只引用 AppStyle::color() / ThemeManager::instance().color()
```

### 主题切换

支持 **浅色 / 深色 / 跟随系统** 三态，运行时切换、QSettings 持久化、无白闪。入口：备份与设置 → 主题。

- 浅色值来源：考据静态资源（`ticktick-windows-6.3.3/02-layout-and-visual-style.md`）与 Web 现场（`ticktick-webapp/01:62-75`）。
- 深色值为 KylinList 自定（考据无深色色值证据）。
- 所有 SVG 图标随主题着色（`AppIcons::icon()` / `AppIcons::paint()`）。

### 阴影与浮层外观

所有窗口阴影由应用自绘，不接受系统补画：

- 自有浮层（信息、清单选择、日期选择器、格式岛、选中文字气泡）在窗口标志中声明 `Qt::NoDropShadowWindowHint`，圆角与投影都由 Qt 绘制。
- Windows 仍可能给无边框窗口的窗口类加上 `CS_DROPSHADOW`。`kl::disableNativeWindowShadows()` 在创建原生句柄时统一清除该样式，覆盖菜单、下拉列表、提示框等 Qt 内部弹出窗口；应用启动时安装一次。
- 这样圆角卡片外不会再出现系统画的直角阴影；新增浮层不需要各自重复处理。

### 字体系统与内置字体

字体族通过 `design/TypeSystem.cpp` 的 `fontFamilies()` 统一回退链解析：Windows 中文 → Linux/麒麟常见中文 → 通用无衬线。业务代码只走 `ds::qfont(FontScene)`，不裸构造 `QFont`。

**可选内置字体**：若发布包在可执行文件同目录放置 `fonts/*.ttf` 或 `fonts/*.otf`，`TypeSystem` 启动时会用 `QFontDatabase::addApplicationFont()` 自动注册，随后按同一回退链解析。未放置该目录时完全走系统字体，不产生额外依赖、不增大安装包。这用于「目标机缺中文字体」的离线兜底与跨设备字形一致性。

- 授权边界：内置字体**必须**是 OFL / SIL Open Font License 等允许再分发的开源字体，并把许可证全文放进 `THIRD_PARTY.md` 与发布包。**不得**把微软雅黑等专有系统字体复制进仓库或安装包。
- 候选（OFL / 开源，本机已有但未纳入仓库）：Noto Sans CJK SC、Source Han Sans SC、文泉驿微米黑。兄弟项目 `CaseLawLibrary` / `public-interest-litigation-fund` 的 `frontend/src/assets/fonts/` 提供的是 woff2 子集（Web 用），Qt 5.12 需要 TTF/OTF 源文件。
- 是否真正内置、内置哪一款，由用户按目标麒麟镜像的实际字体清单决定；当前实现只提供机制，仓库内不附带字体文件。

**offscreen 测试的环境问题**：Windows 的 Qt offscreen 平台插件不读系统字体目录，会报 `Cannot find font directory ...` 并退化成无字形截图。`CMakeLists.txt` 已为 Windows 测试自动设置 `QT_QPA_FONTDIR=$WINDIR/Fonts`，CTest 与 `visualPreview()` 截图不再缺字。真实 Windows 桌面与麒麟目标机不走 offscreen，不受影响。

## 布局

```text
┌──────┬────────────────┬──────────────────────────────┬────────────────────────┐
│ 头像 │                │                              │                        │
│ 任务 │ 今天           │ 清单标题 / 计数    排序 ···  │ 日期 / 提醒   ⓘ ×     │
│ 搜索 │ 最近七天       │ 快速添加（一整行）           ├────────────────────────┤
│ 笔记 │ 收集箱         │ □ 任务标题      时间/优先级  │ 标题                   │
│      │ 清单           │ □ 任务标题      清单         │ 正文                   │
│      │ 文件夹与清单   │                              │ □ 检查项（一项一行）   │
│ 本机 │ 历史与回收站   │                              │ 附件（一项一行）       │
│ 设置 │                │                              │ 清单名       A 记录 ···│
└──────┴────────────────┴──────────────────────────────┴────────────────────────┘
```

主窗口采用**功能栏 52px / 可调筛选栏 / 弹性清单列 / 常驻详情列**四列结构。正常宽度下没有选中实体时第四列仍保留，只显示空白背景；第二列可在 180–360px 内拖动，第三、第四列之间的边界也可拖动，两条分割线均为 1px，第一列不可调。分割线周围有透明扩展命中区，拖动时同步更新列宽和分割位置，不把 1px 视觉线当作唯一命中目标。列表标题栏提供第二列显隐按钮，用户主动隐藏不会因窗口拉宽而被擅自恢复。窗口最小为 620×560；可见边框周围有透明八方向缩放手柄，提供对应鼠标光标，Windows 原生缩放与跨平台手柄共同保证边缘和角落可用。宽度不足时先自动隐藏第四列，再自动隐藏第二列；拉宽时反向恢复，并保留用户列宽。第四列自动隐藏后，选中实体会从右侧以约 300px 覆盖详情呈现，不挤压第三列；关闭按钮紧邻日期／提醒，关闭只收起覆盖层。覆盖详情不再使用左边框线，而是在左侧绘制 18px 渐隐轻阴影表示层级，避免顶部窗口控制区残留短线。窗口不使用系统标题栏，各列背景与分割线从内容顶边延伸到底边；顶部 36px 仅预留窗口控制与拖动空间，不是独立色带。最右上角为最小化／最大化／关闭按钮，三个按钮均使用普通灰色悬停背景，关闭按钮不使用红色。详情日期、提醒与信息按钮位于窗口控制区下方。普通窗口使用 10px 抗锯齿圆角、清晰的 `WindowBorder` 实线边框与四周轻阴影；整张圆角 alpha 图通过可分离高斯模糊生成连续阴影，直边与转角不分区叠加，避免直角接缝。阴影按主题缓存小型模板并以九宫格伸缩，最大化时不生成阴影，避免窗口缩放反复执行整窗卷积。边框由 `WindowBorderOverlay` 在内容之上绘制；内容子控件按同一圆角轮廓裁剪，但承载阴影的 `WorkspaceSurface` 本身不裁剪，透明外边距中的阴影不会被误删。边框、内容、阴影在普通状态统一使用 21px 边距，最小化／最大化还原后同步几何。中间列不绘制外缘圆角，避免在第三／第四列分界上端留下缺口。最大化／全屏时取消圆角、阴影、外边距和缩放手柄；顶部空白可拖动，双击切换最大化。

**不设置常驻状态栏**。备份成功、本机数据说明、完成／放弃任务等反馈统一使用 `ToastIsland` 提示岛，位于第三列底部居中。组件封装文本、可选动作与生命周期：默认 3 秒消失，悬停暂停并在离开后按剩余时间继续；新提示替换旧提示，动作执行后立即关闭。完成／放弃提示提供撤销，恢复操作前任务状态。提示岛使用截图指定的固定深灰底、浅灰文字和金色撤销图标，**不随主题切换**；业务代码不拼接其颜色或定时器。保存或恢复失败仍显示就地错误，不静默丢弃编辑内容。

### 按钮收纳原则

- **直接可见**：日期／提醒、信息图标、文档标题和正文、底栏所属清单与格式入口。
- **行内呈现**：已有检查项与附件自然排在正文流中；为空时无分区占位。标题与正文仍分别保存，共用一个滚动区。
- **格式操作**：底栏 A 展开单排悬浮工具岛；标题、粗体、高亮、检查项、列表、斜体、下划线、删除线分组排列，附加操作收进溢出菜单。
- **实体操作**：完成状态、优先级、置顶、贴桌面、类型转换、活动日志、便签外观 → 详情更多菜单。
- **视图操作**：视图切换 → 列表头部 overflow 菜单。
- **应用级**：备份、主题、自启、退出 → 侧栏底部图标菜单。

## 交互约定

- 新建必须有标题；内容防抖自动保存，保存失败保留编辑内容、显示可操作错误，不悄悄覆盖。
- 所有格式按钮有 SVG 图标和工具提示；低频格式收进二级菜单。
- 时间没有勾选即无约束；默认时区为 `Asia/Shanghai`，带时刻的日期按任务时区显示、以 UTC 时刻保存。
- 删除任务进入回收站；永久删除二次确认；关闭便签只取消贴到桌面。
- 菜单/文本编辑不抢全局 Ctrl+N/Ctrl+D，快捷键只在应用内生效。
- 主题切换运行时生效，所有控件、图标、自绘 delegate 同步更新。
