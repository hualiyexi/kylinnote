# 聚合使用统计

更新日期：2026-11-14。本文说明麒麟清单使用统计的口径与数据边界：客户端只看本机统计，全局聚合只在服务端管理页。统计不是账号同步，也不影响本地任务、笔记与桌面便签。

## 客户端只显示本机统计

「备份与设置 ▸ 使用统计…」打开的窗口只展示这台设备自己的四项数据：

- 累计创建任务、累计创建笔记、累计完成任务、首个任务距今（尚未创建过任务时显示“尚未创建”）。

它**不显示**全局聚合结果、下载量、上报状态或任何错误提示；上报在后台静默进行，成功失败都不进入界面。想知道全局汇总，需要管理员自行访问服务端管理页（见下文）。

## 上报行为与数据边界

- 服务器地址沿用「备份与设置 ▸ 更新服务器」的设置：正常生产运行下启动约 30 秒后首次上报，之后每小时上报一次；单次请求 10 秒超时，在途请求不重叠，失败等下一周期。留空服务器地址即同时停用更新检查与统计上报。
- 上报只有 `schemaVersion` 和四个聚合值：累计创建任务数、累计创建笔记数、累计完成任务数、首个任务距今天数。**不发送任务/笔记 ID、标题、正文、附件、文件路径、installation UUID 或设备 UUID**，也不发送实体内容。
- 显式 `--data-dir` / `KYLINLIST_DATA_DIR` 隔离运行和 `--smoke-test` 禁止自动上报；自动化测试只使用合成数据与本地 HTTP 夹具，不向生产服务器发送测试数据。

## 本机统计口径

统计来自既有实体事件日志，而不是只数当前列表：

- 创建任务/笔记：累计 `created` 事件，回收站或永久删除不清除历史计数。
- 完成任务：按曾经进入完成状态的不同任务去重；同一任务重新打开后再次完成不会增加“完成任务数”。
- 首个任务天数：本机最早任务创建时间到当前时间已经过的完整 24 小时天数；尚未创建任务时上报为 `null`。

## 服务端聚合与 /s 管理页

- 全局聚合结果只在服务端管理页 `<服务器基础地址>/s/` 展示；**首页没有指向 /s 的入口**，地址由管理员自行访问。访问 `/s` 时 nginx 以相对 `Location: /s/` 跳转（`absolute_redirect off`），不暴露绝对地址。
- /s 页面与统计接口**无鉴权**，只依赖“部署在可信内网、不暴露公网”的边界，仅限管理员自行访问。
- 服务器使用宿主 nginx 写入的真实客户端 IP 识别用户。同一 IP 的多次上报只保留最新快照，不会把每小时的数据重复相加；同一 NAT/出口 IP 后的多个客户端按一个用户计算，这是本功能的既定口径。
- API 与页面都**不返回 IP 明细**，只返回聚合值。

### 聚合字段

- `users`：上报过使用数据或有有效安装包下载记录的不同 IP 数（两者并集）。
- 全体创建/完成数：各 IP 最新快照之和；`longestUsageDays` 取各快照中的最大值。
- 下载量：nginx 对 `/updates/files/<版本>/...` 的 GET 且 HTTP 200 请求，按 `request_id` 去重；网页下载和客户端更新下载使用同一口径。它表示下载请求次数，不等于独立设备数。
- `byVersion` 按版本列出下载次数。下载日志增量导入 SQLite，日志轮转或清理不会清除已导入统计。

## HTTP 接口

所有路径相对于更新服务器基础地址，保持纯 HTTP 可信内网边界，不得暴露公网。`summary` 供 /s 管理页读取，客户端不再请求它。

### `POST api/v1/stats/usage`

```json
{
  "schemaVersion": 1,
  "tasksCreated": 12,
  "notesCreated": 3,
  "tasksCompleted": 8,
  "firstTaskDays": 25
}
```

`firstTaskDays` 可为 `null`。请求体最大 8 KiB，字段固定且计数有范围校验；真实 IP 只从代理链获取，绝不接受请求体自报 IP。

### `GET api/v1/stats/summary`

```json
{
  "schemaVersion": 1,
  "generatedAt": "2026-11-14T08:00:00+00:00",
  "users": 2,
  "usage": {
    "tasksCreated": 20,
    "notesCreated": 5,
    "tasksCompleted": 13,
    "longestUsageDays": 40
  },
  "downloads": {
    "total": 6,
    "byVersion": [{"version": "1.3.0", "count": 6}]
  }
}
```

响应不包含 IP 明细或原始上报内容。服务端实现与部署说明见 `server/stats/README.md`；部署、日志轮转与备份见 `kylinlist-deploy/README.txt`。

## 测试

- `tests/tst_stats.cpp`：本机计数口径与事件日志回填、上报 JSON 白名单字段（不含标题/ID）、每小时自动上报与手动停止、失败/超时/不重叠、summary 解析各类错误，均使用本地 HTTP 夹具与临时目录。
- `server/stats/test_stats.py`：请求体严格校验、按 IP 覆盖快照、下载日志增量导入与 `request_id` 去重、summary 聚合，只使用合成数据。

隔离运行（`--data-dir` / `--smoke-test`）不自动上报由 `KylinListApp` 的初始化分支保证，该分支本身没有独立用例；手动验证方式是用隔离目录启动并观察服务器无新快照。
