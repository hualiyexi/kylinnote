# 06 设置与快捷键

研究日期：2026-11-07；本章只描述滴答清单 Web，不代表 Windows 客户端或其他平台。
设置事实来自 [field-notes.md](field-notes.md)；键位采用主会话从真实快捷键页取得的展示值，不另行搜索。
发布实现引用 [code-evidence.md](code-evidence.md) 及 [component-code-evidence.md](component-code-evidence.md) 的章节与 R 编号。
设置浏览、键位展示与功能执行分开记账；没有因看到命令就认定已验证其行为。
配图说明：图片顶部新增的 36px 图注为成册标注，并非产品原生样式；灰块为私人内容遮挡。

## 1. 设置入口与弹窗分区

共同入口为头像 → 设置；左侧分类导航，右侧内容独立滚动。
现场弹窗为 800 × 680 CSS px，左上 x=350、y=130，左栏约 213px。
这些是 1500 × 940 CSS px 研究视口下的尺寸，不是所有窗口的固定值。

| 分区 | 可见组织 | 覆盖边界 |
| --- | --- | --- |
| 左侧分类 | 13 类，顺序见下表 | 已导航查看，不代表所有二级动作都执行 |
| 右侧内容 | 对应设置内容、独立滚动 | 未复制账号原文和私人模板 |
| 关闭与跨页查看 | 设置内导航及退出 | 不以采集期间叠层异常作设计结论 |

当前主题是用户自选的粉色渐变、卡片式界面，不是默认配色结论。

## 3. 功能开关的授权例外与恢复

通常只导航设置、不改值；唯一设置写入例外是用户明确授权临时开启三个模块用于研究。
授权不包括创建习惯或任务、打卡和启动计时。

| 模块 | 采集前 → 临时开启 → 恢复 | 现场恢复凭证 |
| --- | --- | --- |
| 四象限 | false → true → false | 主会话逐项实读 checked，功能条对应入口移除 |
| 习惯打卡 | false → true → false | 主会话逐项实读 checked，功能条对应入口移除 |
| 番茄专注 | false → true → false | 主会话逐项实读 checked，功能条对应入口移除 |

恢复已由主会话完成；本章只整理现场记录，不声称本章节编写过程操作了开关。
日历、倒数纪念日、AI 原本开启且未变更；这只是本账号配置，不是新账号默认配置。
用户开通会员后，日历七种视图已复核可见，早期月视图限制不能沿用为最终结论。

## 5. 快捷键抄录约定

- 下列均为本账号 Web 快捷键页展示，未实测执行，不保证所有平台或输入场景通用。
- `+` 保留页面组合键写法；`→` 明确表示“先按前键，然后按后键”，不是同时按。
- 单字符按键按页面显示记录，不补写 Shift、键盘布局、焦点或输入法条件。
- 键位是否可自定义、是否被浏览器拦截、是否在正文输入时生效，均未验证。
- 实际在搜索输入处用 Escape 关闭面板的观察，只能证明该次退出，不补证全部快捷键。
