# 02 导航、清单与搜索

研究日期：2026-11-07；对象为滴答清单 Web，不是 Windows 客户端。
本章事实来自 [field-notes.md](field-notes.md) 的菜单、设置、搜索及工作区补查记录。
发布实现引用 [code-evidence.md](code-evidence.md) 及 [component-code-evidence.md](component-code-evidence.md) 的 R 编号与章节；不代表取得原始源码。
“已观察”指入口、页面或菜单已展开，不代表其中的修改命令已经执行。
配图说明：图片顶部新增的 36px 图注为成册标注，并非产品原生样式；灰块为私人内容遮挡。

## 1. 导航分区与明确入口

| 分区 | 入口或位置 | 已观察内容 | 边界 |
| --- | --- | --- | --- |
| 功能条 | 工作区最左侧 | 在任务工作区与功能模块间导航 | 模块显隐受本账号设置影响 |
| 清单侧栏 | 功能条右侧 | 智能清单、普通清单、过滤器、文件夹等对象 | 不记录私人名称与数量 |
| 用户菜单 | 点击头像 | 设置、统计、高级会员、退出登录 | 仅菜单已观察，不代表全部页面已进入 |
| 工作区工具栏 | 当前视图顶部 | 视图切换、更多、分组排序等入口 | 内容随列表、看板、时间线变化 |
| 搜索 | 导航搜索入口 | 悬浮搜索面板及四种范围 | 不等同于已执行云端检索 |
| 设置中的导航配置 | 头像 → 设置 → 智能清单 | 智能入口及显示策略 | 查看设置不等于更改侧栏 |

本轮参考视口为 1500 × 940 CSS px，使用用户自选主题。
现场功能条约 50px、清单侧栏约 249px；这些数字不能直接推广到所有视口。
导航的像素宽度与伸缩约束分别有代码证据，见本章第 9 节。

## 2. 导航对象与覆盖层次

| 对象 | 现场证据 | 可确认内容 | 不作出的结论 |
| --- | --- | --- | --- |
| 所有 | 智能清单右键菜单 M01 | 有隐藏入口 | 未验证隐藏后的恢复路径 |
| 收集箱 | 右键菜单 M02 | 编辑、有内容时显示、隐藏 | 不把其当前策略当产品默认 |
| 普通清单 | 右键菜单 M03 | 独立的清单管理命令 | 未复制、共享、归档或删除 |
| 过滤器 | 右键菜单 M04 | 编辑、置顶、复制、删除 | 未验证筛选条件的编辑与保存 |
| 文件夹 | 已置顶文件夹菜单 M05 | 添加清单、编辑、取消置顶、解散 | 未创建清单或解散文件夹 |
| 已完成 | 进入视图并选择条目 | 完成日期分组、三个过滤器与打印 | 未修改完成时间或打印 |
| 其他智能入口 | 设置 → 智能清单 | 页面列出名称和显示策略 | 不等于每个目的页面均已打开 |

智能清单设置中实际列出的入口如下；此表记录配置范围，而非逐页操作验收。

| 类别整理 | 页面列出的项目 |
| --- | --- |
| 汇总与时间 | 所有、今天、明天、最近7天 |
| 分派与收集 | 指派给我、收集箱 |
| 聚合与检索辅助 | 摘要、标签、过滤器 |
| 任务生命周期 | 已完成、已放弃、垃圾桶 |

本表的分类是本章整理方式，不声称是产品的官方分组。
显示策略存在下拉入口，但本轮未更改；不补写未记录的选项全集。
清单、过滤器与文件夹不能因位置相邻就视为同一种数据对象。

## 3. 侧栏上下文菜单

入口为对应侧栏对象的上下文菜单；采集方式及其限制见第 10 节。

| 菜单 | 对象状态 | 实际项目 | 状态含义 |
| --- | --- | --- | --- |
| M01 | 智能清单“所有” | 隐藏 | 本轮只取得这一项目 |
| M02 | 收集箱 | 编辑 / 有内容时显示 / 隐藏 | 显示策略与对象编辑分开 |
| M03 | 普通清单 | 编辑 / 置顶 / 复制 / 共享 / 归档 / 删除 | 存在协作与生命周期入口 |
| M04 | 过滤器 | 编辑 / 置顶 / 复制 / 删除 | 本例没有普通清单的共享、归档项目 |
| M05 | 已置顶文件夹 | 添加清单 / 编辑 / 取消置顶 / 解散 | “取消置顶”与当时已置顶状态相符 |

上述菜单均未执行变更项目。
不能把 M05 的“取消置顶”写成所有文件夹始终显示的命令。
“解散”与“删除”保持页面原词，不推断解散后子清单的存续、顺序或归属。
菜单差异只能说明本轮对象与状态不同，不足以推出完整权限矩阵。

## 4. 层次、置顶与跨区入口

| 观察点 | 入口 | 已知事实 | 仍缺证据 |
| --- | --- | --- | --- |
| 文件夹管理 | 文件夹菜单 | 有添加清单与解散入口 | 新建、解散后的层次变化 |
| 对象置顶 | 普通清单、过滤器菜单 | 两类对象均有置顶项目 | 置顶后的排序与同步 |
| 取消置顶 | 已置顶文件夹菜单 | 菜单反映当前置顶状态 | 未执行状态转换 |
| 清单目标树 | 任务菜单 → 移动到 | 展开搜索框与清单/文件夹层次 | 未选目标、未移动任务 |
| 清单显示 | 设置 → 智能清单 | 有显示策略入口 | 未更改后的实时反馈 |

“移动到”属于任务操作中的目标选择器，不是清单侧栏的独立导航页。
该子菜单在悬停并等待后成功展开；早期未取得子菜单的记录不应解释为缺少功能。
目标树只用于确认层次展示，私人清单名不进入正文。

## 6. 搜索面板与检索范围

入口为导航中的搜索；快捷键页展示 `/`，但该键位本轮未实测触发。
搜索浮在当前模块上方，不要求将其描述为一次独立的整页跳转。

| 范围 | 面板已观察内容 | 覆盖边界 |
| --- | --- | --- |
| 任务 | 范围选项可见 | 不等于已验证任务正文、附件等检索字段 |
| 标签 | 范围选项可见 | 不记录私人标签名 |
| 清单 | 范围选项可见 | 未验证结果点击后的目的视图 |
| 过滤器 | 范围选项可见 | 未验证已保存过滤条件的匹配规则 |

| 搜索状态 | 现场反馈 | 不能扩展成的结论 |
| --- | --- | --- |
| 空搜索 | 提示输入关键词 | 不推断默认历史、推荐或排序算法 |
| 中性随机关键词 | 没有本地结果，显示云端搜索入口 | 不代表账号内没有任务或服务端没有结果 |
| 云端搜索 | 入口可见 | 未执行请求，无法评价速度与召回 |
| 退出面板 | 在搜索输入处按 Escape 后控件消失 | 关闭不代表删除查询历史 |

一次尝试填入空字符串未实际清空输入；不能将工具调用意图当成清除成功证据。
最终只确认搜索控件已退出，不宣称搜索历史已删除。
搜索结果选中、跨范围切换后的匹配差异及云端结果均未完成验证。

| 项目 | 本次测得或观察的值 | 适用范围 |

| 面板大小 | 560 × 422 CSS px | 当前视口、当前面板状态 |
| 左上位置 | x=470、y=160 | 1500 × 940 CSS px 研究视口 |
| 表面 | 白底、12px 圆角、阴影 | 当前主题与现场状态 |
| 定位与裁切 | 现场样式为 absolute、overflow hidden | DOM/计算样式观察，不代替发布源码定位 |

以上是现场测量，不是搜索面板始终固定为 560 × 422px 的声明。
追加代码核查把发布约束与实测值分开，证据为 component-code-evidence §2，S2，R5。

| 发布约束 | 静态证据内容 | 与现场测量的关系 | 证据 |
| --- | --- | --- | --- |
| 宽度 | 80%，最大 560px | 当前宽视口测得 560px，窄视口不能照搬 | component-code-evidence §2，S2，R5 |
| 高度 | 422px，最大 80% | 当前测得 422px，仍有最大高度约束 | component-code-evidence §2，S2，R5 |
| 外层与关闭 | fixed 遮罩；不可见时不渲染；点击遮罩自身关闭 | 不等于所有子层都是 fixed，关闭行为未逐项实测 | component-code-evidence §2，S2，R5 |

上述三项均据 component-code-evidence §2，S2，R5，不以样式名称推断定位机制。
没有把搜索的面板尺寸套用到设置、任务日期或全部菜单。

## 8. 已完成导航页的特殊性

入口为已完成智能视图；这一页不能简单当成普通清单只读副本。
其顶部有“所有日期 / 所有清单 / 所有完成”三个过滤器，并有打印入口。
“所有完成”下拉为“我完成的 / 所有完成”，区分完成者范围，不是已完成/已放弃的状态切换。
内容按完成日期分组；本轮只展开过滤器，没有选择新条件或执行打印。
选中已完成条目后取得状态相关菜单，包含修改完成时间入口。
这一状态差异的细目见 [第 03 章](03-task-interactions.md)，不在此重复推导任务写入结果。

## 9. 导航与菜单的发布代码证据

| 声明 | 可追溯证据 | 结论边界 |
| --- | --- | --- |
| 导航条明确采用 50px 宽度、纵向 Flex 且不伸缩 | code-evidence §4，R5 / R7 | 固定宽度不等于固定定位 |
| 主容器采用 Flex、满高并裁切溢出 | code-evidence §4，R5 / R7 | 不代表所有子栏均分宽度 |
| 清单侧栏有折叠为零及窄屏覆盖分支 | code-evidence §4，R5 | 不能固定宣称侧栏永远为 249px |
| 一组下拉菜单存在尺寸、滚动、悬停与禁用视觉规则 | code-evidence §6，R7 | 不把该规则推广给全部菜单体系 |
| 菜单包装存在点击触发、溢出调整与悬停子菜单实现 | code-evidence §6，R3 | 不代表每个入口使用相同触发方式 |
| 搜索局部类映射、实际组件引用及打开事件链存在 | component-code-evidence §2，S1 / S4，R5 | 不由事件链推断具体全局快捷键 |
| 搜索分类分支还含 event，输入区分键盘建议与文本变化处理 | component-code-evidence §2，S3 / S5，R5 | event 仅代码可见，不增加现场四种范围的数量 |

代码证据只解释已有定位的实现；不据此猜测搜索索引、路由架构或账号权限。
压缩发布包与 CSS 不是已经取得的原始工程源码。

## 10. 覆盖与后续核查边界

- 部分菜单通过已识别 DOM 元素触发，不能冒充原生鼠标、键盘或触摸验收。
- 本轮未创建、删除、置顶、移动、共享或归档清单，也未保存过滤器。
- 统计目的页、导航拖拽排序、云端检索、清单权限差异仍缺操作证据。
- 未验证搜索焦点循环、读屏、对比度及完整键盘路径；不作可访问性合规判断。
- 当前 IAB Chromium 152 仅用于研究；未测试 `C:/Chrome78` Chromium 78。
- 唯一设置写入例外是经用户授权临时开启三个模块；主会话已实读 checked，逐项恢复 false 并确认对应入口移除。
