## 这次已可靠确认的重点

1. **Web发布包包含React/ReactDOM 17.0.2实现声明、Webpack分块线索、Tailwind v3.2.7产物标识及真实局部类映射。** 不只是从网站外观猜技术栈；不等于取得完整依赖树或读取运行时隐藏状态。
2. **主工作台是定宽功能条＋受控侧栏＋弹性列表＋受约束详情。** 现场功能条50px、普通导航行36px、任务单行40px、详情底栏48px；都是特定环境采样，不是不可变的全站规范。
3. **编辑器不只有一种。** CodeMirror有初始化证据，正文组件另有ProseMirror view/附件/只读边界；任务选择、上下文菜单和搜索输入也有事件调用证据。
4. **菜单是按对象、状态、入口与模块配置变化的。** 笔记、完成任务、垃圾桶、多选与普通任务不相同，详情底部更多也不是右键菜单的复制。
5. **会员升级后已经重查。** 日/周/月/年/日程/多日/多周均能打开；看板、时间线、四象限、专注、习惯、倒数和AI入口均有现场观察。AI仍停在隐私同意门，没有代为同意或发送内容。
6. **成熟产品值得参考，但不等于所有决策都适合本项目。** 推荐优先借鉴信息层级和操作一致性，不照搬付费/云协作/AI入口或迁移技术栈。
