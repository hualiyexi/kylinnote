事实依据为 [field-notes.md](field-notes.md) 的会员复核、模块补查与工作区视图记录。
静态实现引用 [code-evidence.md](code-evidence.md) 及 [component-code-evidence.md](component-code-evidence.md) 的章节、R 编号和证据号。

## 2. 会员状态：以升级后复核为准

早期月视图曾出现会员提示；用户随后明确表示已开通会员并要求重新访问。
升级后日、周、月、年、日程、多日、多周均出现实际内容，未再出现原月视图会员提示。
AI 入口的原会员提示也已消失，但这不代表已经获得回复或验证写入能力。
本章不保留“月视图当前被会员限制”的旧结论，也不推导全部会员、协作或地区权益规则。

## 3. 日历七种视图

共同入口为日历模块的视图选择器；七种均有升级后现场页面证据。

| 视图 | 稳定页的可见组织 | 本轮状态或配置边界 |
| --- | --- | --- |
| 日 | 时间轴、全天区域 | 页面已查看，未安排任务 |
| 周 | 时间轴、全天区域 | 页面已查看，未拖动时间块 |
| 月 | 日期表格 | 原会员提示已消失，未编辑日期格 |
| 年 | 多月缩略网格 | 不将缩略格视为已验证的可编辑区域 |
| 日程 | 按日期纵向列出任务 | 只查看组织方式，不记录私人任务 |
| 多日 | 多日视图实际内容 | 复核时本账号原配置为 3 日，不是默认值声明 |
| 多周 | 日期表格 | 复核时本账号原配置为 2 周，不是默认值声明 |

早期选择器曾显示其他多日、多周数值，不能把不同采样值拼成统一默认设置。
日与多日、月与多周存在共用路由的现场记录，因此不能以地址变化次数统计视图种类。
日历 DOM 中还有大量屏外周行；完整 DOM 数量不等于当前可视区网格数量。
键位页展示的日历快捷键见 [第 06 章](06-settings-and-shortcuts.md)，本轮未实测键位切换。
