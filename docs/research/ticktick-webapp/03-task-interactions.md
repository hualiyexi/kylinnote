# 03 任务行、详情、日期与状态交互

研究日期：2026-11-07；范围是滴答清单 Web 的现场任务界面，不代表 Windows 客户端。
事实来源为 [field-notes.md](field-notes.md) 的任务详情、菜单、日期与工作区补查。
发布实现引用 [code-evidence.md](code-evidence.md) 及 [component-code-evidence.md](component-code-evidence.md) 的 R 编号和章节，未取得原始工程源码。
任务标题、正文、关联内容、清单名和标签名均不复制；下文只描述控件与状态。
配图说明：图片顶部新增的 36px 图注为成册标注，并非产品原生样式；灰块为私人内容遮挡。

## 1. 操作层次与明确入口

| 层次 | 入口 | 本轮已完成 | 未执行 |
| --- | --- | --- | --- |
| 任务行 | 列表中的任务条目 | 查看条目、选中并查看详情 | 完成、编辑、拖动 |
| 任务菜单 | 条目上下文菜单 | 展开根菜单及部分子菜单 | 点击写入命令 |
| 任务详情 | 选中任务后出现的详情区域 | 读取分区、展开日期层 | 修改标题、正文、子任务 |
| 日期层 | 详情顶部“设置日期” | 展开日期面板 | 选择日期、清除或确定 |
| 标签选择 | 任务菜单 → 标签 | 打开列表与取消/确定入口 | 勾选标签或提交 |
| 移动目标 | 任务菜单 → 移动到 | 展开搜索及清单/文件夹层次 | 选择目标或移动任务 |
| 已完成记录 | 已完成视图 → 选中条目 | 查看分组和状态相关菜单 | 修改完成时间 |

现场任务行约 40px，是当前样式与视口的采样，不是所有密度、内容状态的固定行高。
“展开了命令”与“执行了命令”必须分开；本轮没有完成任何任务写入操作。

## 3. 日期弹层：结构与边界

入口为详情顶部“设置日期”；本轮只展开、查看，没有改值。

![任务详情的日期弹层](assets/03-tasks/t01-date-picker.png)

| 区域 | 现场内容 | 已观察状态 | 未验证内容 |
| --- | --- | --- | --- |
| 类型切换 | 日期 / 时间段 | 两种入口可见 | 时间段的选择与保存 |
| 快捷区 | 4 个快捷图标 | 当前详情日期层的样本 | 图标全部 tooltip 与执行效果 |
| 月份导航 | 月份翻页入口 | 控件可见 | 翻页后选择与提交 |
| 日期网格 | 周一至周日、42 格 | 当前日期面板布局 | 每周首日等其他配置组合 |
| 时间 | 时间入口 | 初次超时，后续已补查时间列表与输入框 | 未选时间、未验证输入校验 |
| 提醒 | 提醒入口 | 后续已展开提醒选项 | 未选择、未验证实际触发 |
| 重复 | 重复入口 | 后续已展开周期选项 | 未选择周期、未保存规则 |
| 底部动作 | 清除 / 确定 | 两个动作可见 | 是否写入、撤销及同步 |

一次日期层未随模拟导航关闭、与设置重叠，是采集污染；不认定为正常设计或产品缺陷。
该异常画面不能作为日期层与设置层可同时使用的证据。
早期时间入口的工具超时已被后续补查补足，不能保留为“没有时间设置”的结论。

| 后续展开的子层 | 现场内容 | 仍未覆盖 |
| --- | --- | --- |
| 时间 | 00:00 至 23:30 的半小时列表、“设置时间”输入框 | 建议时刻及默认提醒文本未保存，不验证校验规则 |
| 提醒 | 当天、提前 1/2/3 天、提前 1 周均显示 09:00，另有自定义、持续提醒、取消/确定 | 09:00 是本次界面值，不是跨账号默认值；未选择 |
| 重复 | 每天、每周、每月、每年、工作日、节假日、艾宾浩斯记忆法、自定义 | 动态星期/日号不当固定文案；未进入自定义深层配置 |

后续补查使用无日期任务，每次点击头部空白取消，并核对“设置日期”占位仍在、日期层已隐藏。
没有点击确定、清除或任何日期、时间、重复选项；看到建议值不等于已写入任务。

## 4. 菜单中的日期与优先级快捷区

任务上下文菜单的快捷区与详情日期层不是同一份控件清单。
早期已置顶主任务样本记录为日期 4 图标与禁用省略项；后续有日期任务样本为 6 图标。
这些是不同采样状态，不能统一改写成所有任务永久具有相同数量的快捷按钮。

| 现场记录项 | 已有证据 | 本章采用的表述 |
| --- | --- | --- |
| 日期图标标识 | `quick-today`、`tomorrow-list`、`quick-nextweek` | 仅记录现场 DOM 标识，不把执行结果视为已验证 |
| 日期图标标识 | `quick-nextperiod` | 未核对 tooltip，不翻译成确定业务命令 |
| 日期图标标识 | `date-unselected`、`quick-clear` | 不仅凭名称推断完整业务语义 |
| 优先级 | 高 / 中 / 低 / 无，四档图标 | 四档入口已观察，未选择新值 |
| 省略项 | 早期样本有禁用省略项 | 不能仅凭视觉确认业务事件保护 |

上述图标标识来自现场 DOM 记录，不是本章新增的发布源码定位。
日期图标的识别与快捷键页上的“今天、明天、下周”命令应分别引用，不能互相补证执行效果。

| 层级关系 | 添加子任务、关联主任务 | 添加子任务、关联主任务 |

| 专注入口 | 早期样本未记录此项 | 临时启用专注后出现开始专注 |

“开始专注”与模块启用状态相关，不应作为所有任务菜单的固定项目。

## 6. 移动到、标签与子菜单等待

| 入口 | 展开后的内容 | 方法与状态 | 未做的操作 |
| --- | --- | --- | --- |
| 任务菜单 → 移动到 | 搜索框、清单/文件夹层次 | 悬停右箭头并等待约 400ms 后取得 | 不选目标 |
| 任务菜单 → 标签 | 标签列表、取消、确定 | 已打开列表 | 不勾选、不确认 |
| 任务菜单 → 添加子任务 | 命令可见 | 没有进入创建流程 | 不新增子任务 |
| 任务菜单 → 关联主任务 | 命令可见 | 没有完成关联选择 | 不更改父子关系 |

早期“移动到”未取得子菜单是采集未完成，后续已补查成功，不能写成没有子菜单。
搜索框和层次树的存在不证明任意目标都可移动，也不证明跨共享权限操作已覆盖。
标签弹层只证明选择界面存在，不证明多选、取消、提交的持久化效果。

## 7. 笔记行与任务行不能混写

入口为笔记行上下文菜单；本例实际包含以下项目。

| 分组 | 笔记行已观察项目 | 与任务样本的区别 |
| --- | --- | --- |
| 时间与置顶 | 日期、置顶 | 未记录任务样本中的优先级项 |
| 归属与分类 | 移动到、标签 | 有相同名称的分类入口 |
| 专注 | 开始专注 | 发生在临时启用专注之后 |
| 复制与转换 | 创建副本、复制链接、转换为任务 | 转换方向与任务菜单相反 |
| 删除 | 删除 | 未执行 |

本例没有任务菜单中的添加子任务、优先级、放弃项目。
这仅是已观察的类型差异，不能据此推导所有笔记形态或权限的菜单全集。
没有执行任务与笔记互转，无法说明正文格式、日期或状态的转换规则。

## 8. 已完成状态与修改完成时间入口

入口为已完成视图；顶部实际为所有日期、所有清单、所有完成三个过滤器。
“所有完成”下拉实际只有“我完成的 / 所有完成”，是完成者范围，不是已完成/已放弃状态切换。
任务按完成日期分组；本轮只展开该下拉，没有选择新条件，头部打印也未执行。
选中的样本是“已完成且仍置顶”的任务，不是所有完成记录的代表。

| 菜单组 | 本例实际项目 |
| --- | --- |
| 日期与优先级 | 日期、优先级 |
| 关系与置顶 | 关联主任务、取消置顶 |
| 状态与归属 | 放弃、移动到、标签 |
| 专注与链接 | 开始专注、复制链接 |
| 完成记录 | 修改完成时间 |
| 删除 | 删除 |

本例未出现添加子任务、创建副本、转换为笔记；不外推为所有已完成类型都不具备这些能力。
没有修改完成时间，不能描述其输入面板、校验范围或统计影响。
已放弃页面及任务放弃操作仍缺证据；不能由配置入口推断其稳定页面内容。
垃圾桶后续已补查：稳定后有现存删除项目，首次空态是加载临时态，不代表账号实际为空。

| 垃圾桶入口 | 实际内容 | 本轮边界 |
| --- | --- | --- |
| 垃圾桶头部 | 清空垃圾桶 | 未执行 |
| 现存删除项上下文菜单 | 恢复 / 永久删除，仅两项 | 只展开，未恢复或永久删除 |

不复制删除项内容，不推断保留期限、恢复归属或永久删除的确认流程。

## 10. 详情适配、菜单规则与尚未覆盖事项

| 实现结论 | 可追溯证据 | 适用边界 |
| --- | --- | --- |
| 详情默认宽度类为 36%，大尺寸分支有 320px 最小宽度 | code-evidence §4，R5 / R7 | 不是所有状态的最终实测宽度 |
