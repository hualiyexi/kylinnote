## 2. 当前菜单与按钮的真实现状

### 任务右键

[TaskPanel:409–464](<../../../src/ui/TaskPanel.cpp#L409-L464>)：

- 正常任务：完成任务/设为未完成；贴到桌面/取消贴到桌面；复制为新任务；分隔线；移到回收站。
- 回收站任务：只有恢复任务。
- 正常任务的这些状态修改先 `flush()`；复制不是附件全量克隆，不能在新 UI 中承诺“完整复制所有材料”。

### 分组与备份菜单

- [分组菜单:466–506](<../../../src/ui/TaskPanel.cpp#L466-L506>)：新建；重命名当前分组；删除当前分组。后两项仅真实分组可用；删除确认后任务移至未分组，保留任务。
- [备份与设置:508–556](<../../../src/ui/TaskPanel.cpp#L508-L556>)：导出、导入、登录自启、打开数据位置、退出。导入是合并为新任务，重复导入会产生副本。

### 便签与提醒

- [TitleBar:23–55](<../../../src/ui/TitleBar.cpp#L23-L55>)中的 `···` **直接打开详情，不是更多菜单**；色点轮换六色；×只取消贴桌面。若更换图标/菜单，需同步改文案和工具提示，避免图形暗示错误。
- [托盘菜单](<../../../src/app/TrayController.cpp#L15-L48>)已有打开面板、新建任务、新建桌面便签、显示/隐藏便签、退出。
- [提醒弹窗](<../../../src/ui/ReminderPopup.cpp#L34-L62>)已有稍后10/30/60分钟、查看任务、标记完成、知道了；“知道了”不等于完成任务。

## 3. 哪些能换 UI，哪些要改模型

| 能力 | 现在有什么 | 判断 |
|---|---|---|
| 三栏、主题、密度 | Qt Widgets、splitter、统一样式及 delegate | 可先做可逆布局/视觉调整 |
| 日期/提醒/重复 | 开始、截止、单提醒；不重复/日/周/月 | 可换编辑入口，不能凭 UI 添加多提醒/复杂 RRULE |
| 优先级 | `0..2` 三档 | 滴答四档不能不经决策直接套入 |
| 子项 | `ChecklistItem(text,done)` 平面清单 | 不是真正有独立身份/日期/附件的子任务 |
| 分组 | `TaskGroup(id,name)`，任务一个 groupId | 不是文件夹→清单→清单内分组的三层 |
| 标签 | 已存字符串标签，当前过滤定义无标签视图 | 基础标签聚合可先扩展过滤层 |
| 排序 | 安排时间/优先级/创建时间/标题 | 手动顺序需新契约；便签 `zOrder` 不能挪用 |
| 快速添加 | 只继承当前实际分组 | “今天里新增即安排今天”、自然语言解析都不是现有能力 |
| 附件 | 独立受管存储，单个≤2MiB | 改上限/复制/重复实例继承须维护事务与备份 |
| 云协作/账号 | 无对应领域/schema | 不能作为皮肤改造顺带实现 |

依据：[任务字段:17–53](<../../../src/domain/Task.h#L17-L53>)、[过滤定义:4–12](<../../../src/ui/TaskFilter.h#L4-L12>)、[快速添加:348–389](<../../../src/ui/TaskPanel.cpp#L348-L389>)、[数据库约束:24–67](<../../../src/db/Database.cpp#L24-L67>)。

## 4. 先解决行为一致性，再精修外观

### 4.1 保存与完成的入口差异：待验证的静态风险

- 详情编辑使用 450ms 防抖：[TaskDetailWidget:25–27](<../../../src/ui/TaskDetailWidget.cpp#L25-L27>)。
- 详情完成前先保存：[TaskDetailWidget:261–265](<../../../src/ui/TaskDetailWidget.cpp#L261-L265>)；右键完成也先保存：[TaskPanel:420–425](<../../../src/ui/TaskPanel.cpp#L420-L425>)。
- 列表完成框/Space 经 delegate 和 model 直接 `setCompleted`：[TaskDelegate:185–204](<../../../src/ui/TaskDelegate.cpp#L185-L204>)、[TaskListModel:82–86](<../../../src/ui/TaskListModel.cpp#L82-L86>)。
- 重复任务完成时用已保存数据生成下一实例：[TaskStore:363–391](<../../../src/app/TaskStore.cpp#L363-L391>)。

因此应补“详情草稿尚未防抖落盘就从列表完成重复任务”的测试，确认下次实例是否使用正确内容。**这是静态路径风险，尚未运行复现，不在本次直接修代码。**

建议统一命令入口：`保存当前必要草稿 → 校验 → 状态操作 → 成功反馈/失败回滚 → 恢复选择和焦点`。

### 4.2 刷新与状态稳定

当前模型刷新执行全量 reset：[TaskListModel:92–102](<../../../src/ui/TaskListModel.cpp#L92-L102>)。分钟时钟只刷新 model，导航计数在另一处重建时计算：[TaskPanel:89–92](<../../../src/ui/TaskPanel.cpp#L89-L92>)、[306–313](<../../../src/ui/TaskPanel.cpp#L306-L313>)。

建议统一跨午夜/逾期刷新入口，并逐步改善局部更新、列表滚动和选中稳定性。这里只是源码改进点，**没有测出性能瓶颈**。

## 5. 推荐的实施顺序

### P0｜不扩业务的视觉与一致性改造

- 保留三栏和原生窗口框架，统一设计令牌与详情硬编码。
- 分组/优先级/星标提升到紧凑属性区，便签颜色/层位留低频区。
- 完成、贴桌面、删除动作归一；补保存前置和失败反馈测试。
- 固定“全部”“七天内”“当前视图新增落点”的语义后再改文案。

**验收：**原有数据与快捷键不回退；选择/滚动稳定；失败不丢草稿；小窗可用。不要承诺像素级与滴答一致。

### P1｜现有数据上的效率增强

- 快速添加日期、分组、优先级快捷入口。
- 拆分 MetaRole 的日期、标签、进度、提醒等呈现，不再一串同色文字。
- 增加基本标签聚合/日期分段；把已有自启、层位、数据管理整理为清晰设置入口。
- 在任务行更多与右键间共享核心 QAction；定义空白区和多选语义。

**验收：**字段级保存、UTC转换、回收站、重复生成和附件上限仍成立；新增入口不会写出模型不能存的值。

### P2｜确有需求才启动模型扩展

真正子任务、文件夹层级、手动排序、可保存高级筛选、更多优先级、多提醒、全天/复杂时区与重复、云同步协作。分别经过领域定义、版本化 schema、Codec/备份迁移、事务与异常测试，再做 UI。当前 schema 与未来版本拒绝规则见 [Database:12–67](<../../../src/db/Database.cpp#L12-L67>)、[120–130](<../../../src/db/Database.cpp#L120-L130>)。

## 6. 必须保留的产品约束

1. **原生 Qt / 离线：**Linux Qt5.12 API、Windows Qt5.15.2、C++14；不为相似视觉引入浏览器、远程字体、CDN 或账号门槛。见 [构建约定](<../../building.md#L3>)、[CMake:8–30](<../../../CMakeLists.txt#L8-L30>)。
2. **任务是单一事实来源：**便签是同一任务的桌面投影，关闭只 unpin；主窗重排不能覆盖窗口几何/颜色/层位。见 [NoteManager:27–85](<../../../src/app/NoteManager.cpp#L27-L85>)。
3. **提醒依赖应用运行：**恢复运行后补发不等于关机唤醒或系统后台服务。见 [ReminderScheduler:12–34](<../../../src/app/ReminderScheduler.cpp#L12-L34>)。
4. **界面保护不是装饰：**焦点、中文输入法、错误反馈、回收站确认和草稿保留均需测试。
5. **平台测试：**原生 Qt 用 QtTest＋Windows/麒麟目标机；未来若新增网页 UI，其前端兼容起点必须是 `C:\Chrome78` 的 Chromium78。本次未运行浏览器兼容测试，不声称已通过。
