## 1. 三种入口必须分别记录

- **右键上下文菜单**：由鼠标所在对象和当前选择集决定。
- **`···` 更多菜单**：由按钮所归属的清单、任务或详情决定，不一定与右键等价。
- **多选批量面板**：选择状态触发的编辑界面，不是右键菜单。

对同一对象，三者可能共用命令，也可能项目/排序/可用条件不同。本轮没有验证等价关系。

## 5. 每个菜单的记录格式

未来每个 M 编号至少保存：

```text
对象与状态：普通清单 / 未完成单任务 / 正文有选区……
入口：右键 / 行尾··· / 详情··· / 多选面板
前置选择：右键是否改变选中项，是否保留多选
项目：逐行原文、图标、快捷键、分隔线、子菜单
可用性：隐藏 / 禁用 / 可用 / 当前勾选
取消：Esc、点击外部、再次点击入口
位置：靠屏幕边缘时的翻转、遮挡和焦点恢复
证据：本机版本、窗口尺寸/缩放、截图、采集日期
```

“未出现”必须有实际展开证据；工具打不开时只能写“未实测”。

## 6. 对 KylinNote 的菜单方案（建议，非滴答复制清单）

### 正常任务

- 状态：完成 / 设为未完成。
- 安排：日期/提醒、优先级、移到分组；只开放模型能保存的选项。
- 展示：贴到桌面 / 取消贴到桌面。
- 复用：复制为新任务；明确是否包含附件。
- 危险操作：分隔线后“移到回收站”。

### 已在回收站的任务

- 恢复任务。
- 如增加“永久删除”，必须明确不可撤销并确认；不要让正常任务与回收站任务混用同一删除含义。

### 菜单实现原则

1. `QAction` 复用同一命令层；右键、工具栏、详情、快捷键不可各写一份状态变更。
2. 多选时只呈现确实支持批量执行的命令；混合状态要定义，不默认第一项代表全部。
3. 分组/标签菜单只在相应对象上出现；空白区菜单不悄悄作用于旧选择。
4. 行尾更多入口应与右键共享核心命令，保证没有右键的设备仍能访问；是否完全一致应明确写进项目规格。

项目当前真实菜单及保存路径参见 [改造映射](<08-kylinnote-adaptation.md>)。
