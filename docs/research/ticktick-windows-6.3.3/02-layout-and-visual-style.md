# 02｜总体布局与视觉风格

> 本章由官方旧图的视觉阅读、本地静态设计令牌和改造建议组成。**没有本机当前界面坐标、栏宽或主题的实测值。**

## 1. 先理解区域职责，不先照抄像素

![官方旧版 Web 布局参考，不代表本机 Windows 当前界面](<assets/official-web-layout-reference.png>)

来源：[官方旧版 Web 番茄计时帮助](<https://help.dida365.com/faqs/6684765710167572480>)。这是旧版 Web 示例，不是 Windows 6.3.3 的界面证据。图中位置只能说明这种布局模式曾被官方采用。

可将研究问题分成四层：

| 区域 | 应承载的职责 | 需要现场确认的细节 |
|---|---|---|
| 全局功能/模块栏 | 在任务、日历、专注等模块间切换；全局更多/通知 | 是否独立窄栏、图标顺序、头像位置、右键、可隐藏模块 |
| 组织导航 | 选择智能清单、文件夹、用户清单、标签 | 当前可见项目、计数、折叠、拖动、标签位置、底部入口 |
| 当前内容区 | 当前清单标题、显示方式、快速记录、任务集合 | 搜索是全局还是当前清单、排序/分组/视图入口、空态 |
| 当前对象详情 | 编辑所选任务、查看正文、时间、子项及附件 | 固定侧栏还是浮窗、关闭/切换行为、保存提示、更多操作 |

这里的“四层”是职责分类，不等于断言当前 Windows 恒定显示四个可见栏。日历并列、收起导航、弹出详情等状态需要分别采集。

### 本地资源能补充什么

安装资源包含 `views/tabbar/leftmenubar.baml`、`views/mainwindow.baml`、任务详情及日历侧栏组件。全局栏引用“同步”“提醒与通知”“更多”三个短文案；**其余图标可能通过代码或绑定生成，不能把这三项当完整功能栏**。详见 [本地资源证据](<resource-evidence.json>)。

## 3. 字体、密度与状态

**本地资源：**正常字号资源包括 `Font10/11/12/13/14/16/18/19/20`，数值与后缀一致；还有 `Height28/32/40/48/54` 等高度资源。资源包另有不同字体/大小配置的名称。

能得出的结论是：它有**统一的排版和尺寸资源层**，而不是每个页面随意设字号。不能据此断言“任务行恒定 40px”“标题一定 20px”或具体字体家族；也没有测量行间距、圆角和阴影。

**旧图视觉阅读：**以文字内容为主、区域分隔较轻、强调色用于选中和操作、任务状态图标与正文并排。这是对所附旧图的观察，不是当前版本的完整风格结论。

### 后续必须实测的状态

- 普通、悬停、选中、键盘焦点是否各有独立表现。
- 完成框命中区和任务行选中区是否分离。
- 逾期、优先级、清单色、标签色是否可能互相冲突。
- 已完成是否弱化、是否删除线、是否留在当前分组。
- 禁用菜单、危险操作、空态、加载/同步/离线/错误如何反馈。
- 鼠标悬停才出现的操作，能否通过键盘或更多菜单找到。

## 4. 对 KylinNote 的视觉转译建议

以下是**设计建议，不是滴答规格**：

1. 保留“浅色导航＋白色任务面＋轻分隔”的方向，先沿用自己的品牌色和图标，避免直接复制品牌资产。
2. 将基础色、强调色、危险色、辅助文字、悬停、选中、焦点分成语义令牌，而不是到处写原始色值。
3. 任务标题为第一层；日期/清单/标签/进度为第二层。不要把所有元信息拼接成一条同色长文本。
4. 详情优先显示标题、日期、优先级、所属分组；正文和子项占主要阅读面积；便签颜色/层位属于低频设置。
5. 提供“舒适/紧凑”密度前先定义命中区；视觉更紧凑不等于可点击区域也缩小。
6. 焦点框、工具提示、中文标签、颜色以外的状态提示必须保留；成熟产品的鼠标效率不能以牺牲可访问性为代价。

实现位置与当前尺寸见 [项目改造映射](<08-kylinnote-adaptation.md>)。后续应在 960×620、1240×820 和高 DPI 下做原生 Qt 验收，而不是只拿一张大窗口截图比较。
