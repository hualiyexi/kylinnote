## 当前能可靠得出的判断

1. **本机滴答是 WPF 桌面应用，不是必须用浏览器复刻的网页。** 值得借鉴的是信息组织与操作模型，不是照搬其技术栈。
2. **任务对象、任务的组织方式、任务的显示视图应分层理解。** 文件夹/清单/分组、标签、日历/看板并不是同一种东西。
3. **本地资源包含成组的字体、颜色、悬停、优先级及显示设置。** 这支持建设统一设计令牌，但不证明用户当前选中了哪套主题。
4. **KylinNote 已有三栏骨架。** 第一阶段应优先优化信息层级与操作一致性，而不是推倒重写或照搬所有高级功能。
5. **成熟产品不等于每个决策都是本项目最佳选择。** 我们是离线 Qt 待办＋桌面便签，云协作、付费入口、AI、复杂习惯统计不应仅因对标而加入。

## 使用提醒

- 标为“建议”的尺寸、布局和菜单分组是 KylinNote 方案，不是滴答实测值。
- 标为“本地资源”的条目只证明安装包包含对应定义/引用，不证明当前可见、可用或处于该位置。
- 官方旧版 Windows、Web、macOS 路径不互相替代。特别不要将旧 Web 的“实验功能”写成当前 Windows 的设置路径。
- 本次没有修改应用任务、设置或账号，没有读取私人任务数据库；没有修改 KylinNote 产品源码，没有提交或推送仓库。
