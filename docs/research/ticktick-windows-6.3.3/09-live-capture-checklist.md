## 2. 恢复后按这个顺序采集

每项勾选前，必须有实际窗口观察和证据，不用公共资源替代。

### A. 环境和总体

- [ ] A01 关于页版本、实际主题、窗口大小、系统缩放；账号信息不入图。
- [ ] A02 主工作台：无选中任务 / 有选中任务各一张。
- [ ] A03 导航折叠、详情收起、任务/日历并列（如本机有入口）。
- [ ] A04 窄窗口、最大化、滚动区域边界和分隔条；不擅改用户已保存布局。

### B. 组织导航

- [ ] B01 智能清单全貌和计数；普通/完成/回收站的差别。
- [ ] B02 文件夹展开/折叠、普通清单、清单内分组。
- [ ] B03 标签显示与标签聚合；不移动/删除标签。
- [ ] B04 搜索入口、搜索范围和无结果；只用无敏感内容的查询，退出恢复。

### C. 任务与详情

- [ ] C01 任务行普通、hover、selected、键盘 focus。
- [ ] C02 长标题、多元信息、有提醒/重复/附件/子项的行；私人内容遮挡。
- [ ] C03 详情顶部、正文、子项、底部；分别滚动截图，避免一张超长图。
- [ ] C04 日期弹层、优先级、所属清单、标签选择；只展开后取消，不提交变更。
- [ ] C05 正文选区工具/链接/编号菜单；避免编辑或保存原任务。
- [ ] C06 多选后的右侧批量面板；取消选择，不执行批量写入。

### D. 菜单专项

- [ ] D01 按 [21处菜单矩阵](<05-context-menus.md>)逐位置采集。
- [ ] D02 同对象的右键与 `···` 分别记录，不假定一致。
- [ ] D03 每个子菜单另外截图；说明父菜单入口。
- [ ] D04 记录隐藏/禁用/勾选项目和快捷键，原文逐项核对。
- [ ] D05 回收站、已完成、重复、多选、空白区分开。
- [ ] D06 只展开托盘菜单，不退出、不置顶/取消置顶。

### E. 模块与设置

- [ ] E01 看板、日历、时间线可见状态和显示设置；不拖动任务。
- [ ] E02 四象限、专注、习惯等只浏览已启用模块，不开启新模块或开始计时/打卡。
- [ ] E03 设置导航和各分类；不修改开关、密码、快捷键、自启、代理或默认值。
- [ ] E04 “不可用/会员提示/模块未开启”如实际出现，记录为当前状态，不当成功能不存在。

每图配短说明：版本、入口、前置状态、看到什么、不能证明什么、遮挡区域、对应文档段落。不要把完整原始 UI 树、私人任务标题或账号原文附在公开证据里。

## 4. 私密截图的处理流程

1. 只从用户指定窗口取得画面；保留原始采样作为临时依据，不进入仓库。
2. 列出账号/任务/附件/成员/路径等敏感区域；优先裁掉无关信息。
3. 对保留区域作不可逆纯色遮挡，不采用可辨认的轻模糊。
4. 在副本上加编号与局部说明，不覆盖关键菜单项，也不重绘菜单内容。
5. 用图像工具逐张检查最终图；检查图像元数据、文件名、图注和旁边的文字。
6. 只有处理后的图片进入手册；原图不加入压缩包或版本控制。

本轮使用的是官方示例和仓库既有演示图，没有接触私人任务截图；**不能把这件事表述为已完成个人截图脱敏测试**。

## 5. 操作安全边界

可以做：选中查看、展开菜单/子菜单、只读设置导航、在不改变数据的情况下退出弹层。

本轮不可做：新增/编辑/完成/删除任务、移动清单/标签、拖动日历/看板、改默认值、自启/锁定/代理/同步设置、上传附件、开始专注或打卡、清空回收站。

只有另有明确授权且隔离资料可用，才做写入行为测试。不要因为“只是研究 UI”而默认具有改真实数据的权限。

## 6. 什么情况下才能改成“实测完成版”

- 版本、主题、缩放与窗口状态有记录。
- 主工作台、任务详情、导航、视图与设置均有本机证据。
- 21处矩阵有结果：已观察/本机不存在该入口/受权限限制；每项都有理由，不能用“未实测”充作覆盖。
- 菜单原文、层级、分隔、快捷键、禁用条件有记录；右键与更多入口区分。
- 所有本机图片经脱敏检查；官方旧图仍保留旧版标识。
- 源码建议仍与事实分开；没有把 UI 相似等同业务能力已实现。
- 如有未完成项，首页继续写明边界，不能宣称全覆盖。

在这些条件满足前，本册仍保持**可用的资料研究版**，不作为按钮定位或像素级改造的最终验收规范。
