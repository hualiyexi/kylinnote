## 2. 设置项的作用范围应另记

同样叫“显示设置”，可能影响不同对象：

- 全局外观：主题、字体大小、密度、语言。
- 任务默认值：只影响新任务，不应被理解为批量改旧任务。
- 当前清单视图：分组、排序、看板尺寸、时间线比例。
- 日历视图：周末、已完成、重复周期、时区、专注/习惯记录。
- 独立小窗：主题、不透明度、置顶、贴边隐藏。

本地资源能支持上述主题的存在，但**设置是否全局共享、按清单记忆、按设备保存，以及何时生效，本轮均未验证**。

## 5. 关闭、托盘、置顶和提醒的边界

- [旧官方 Windows FAQ](<https://help.dida365.com/faqs/6822520748024791040>)记录从系统托盘右键菜单“取消置顶”。这证明旧文有这个操作，不证明当前托盘全菜单。
- 本机“关闭主窗是否退出”“托盘单击/双击”“隐藏/恢复”“提醒弹层的按钮”均未实测。
- 应用锁、自启、快捷键、系统通知属于可能影响用户环境的设置，研究时只打开查看，不切换或测试密码。

## 6. 对 KylinNote 的设置组织建议

当前“备份与设置”其实是一个菜单，不是多页设置中心。可以先建设轻量四组：

1. **通用**：登录自启、关闭到托盘的说明、语言/字体适配（有实现才显示）。
2. **桌面便签**：默认层位、默认颜色、阅读/编辑行为。
3. **任务与提醒**：已有默认值或提醒说明；未实现多提醒/后台服务不要摆出空开关。
4. **数据与关于**：导入导出、数据位置、备份语义、版本。

保留离线、无账号即可使用；不复制成熟商业产品的订阅、账号、安全锁和 AI 分类作为装饰。快捷键优先在应用内生效，保留中文工具提示和冲突说明。具体源码入口见 [改造映射](<08-kylinnote-adaptation.md>)。
